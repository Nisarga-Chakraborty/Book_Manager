# 📚 BookManager – A Simple Java Swing Book Tracking App
BookManager is a desktop application built with Java Swing that helps users manage their reading history and wish lists in an interactive way. It provides a clean interface with customizable features, making it easy to log daily reading sessions and maintain book wish lists.
# ✨ Features
- Modern UI with Swing
- Title panel, toolbar, and scrollable history panel.
- Customizable background color using a color chooser.
- Wish List Management
- Create personalized wish lists.
- Edit and update wish list content anytime.
- Daily Reading Entries
- Add new day entries with automatic date and time stamps.
- Edit notes for each entry using a text editor popup.
- Interactive Toolbar
- Menu options for background customization, wishlist creation, and exit.
- “+ New” menu for adding new day entries.
- Persistent Editing
- Each entry or wishlist can be updated and saved through a simple text area dialog.
# 🛠️ Tech Stack
- Language: Java
- GUI Framework: Swing (JFrame, JPanel, JMenu, JToolBar, JScrollPane, etc.)
- Data Storage: In‑memory HashMap for wish lists and daily entries
# How to Run
- Clone the repository.
- Compile the project: javac BookManager.java
- Run : java BookManager
# 🎯 Use Case
This project is ideal for beginners learning Java Swing and GUI development. It demonstrates:
- Event handling with buttons and menus
- Layout management (FlowLayout, BoxLayout)
- Dialogs (JOptionPane, JColorChooser)
- Scrollable panels for dynamic content
